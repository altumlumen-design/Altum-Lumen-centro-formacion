Acceso exclusivo para alumnos matriculados

Aula Virtual del Centro de Formación y Capacitación Profesional

Espacio académico de consulta para alumnos matriculados, destinado a visualizar aulas por programa, acceder a sesiones grabadas, materiales, evaluaciones y orientaciones para la certificación correspondiente. Cada curso se habilita mediante un código alfanumérico de acceso entregado por la Dirección Académica.

Ingreso por código

Cada curso o diplomado cuenta con un código de acceso de hasta 8 caracteres alfanuméricos. El código permite abrir el aula correspondiente.

Uso académico

Los accesos son de uso exclusivo para participantes matriculados. Si aún no te encuentras inscrito, puedes solicitar matrícula o información por WhatsApp.
